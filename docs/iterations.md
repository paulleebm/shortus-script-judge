DECISIONS 19번의 반복 검증을 바퀴마다 적는다. 바퀴마다 같은 검증 묶음(방향 시험, 독립 참조 판정, 반복 안정성)으로 재고, 끝내는 조건(측정 전에 정함)과 맞대어 본다. 점수표 원문은 `npm run eval -- suite`가 `runs/eval/suite-<프롬프트 버전>.md`에 쓴다.

- 개발용 대본: S00~S13(13개). 시험용 8개는 결과를 본 뒤 개발용으로 옮겼다
- 홀드아웃: H01~H08(`data/holdout/`). 2026-11-20 정해진 규칙(각 목록의 첫 글, 광고·성적·연예인·사망 글 제외)으로 고른 원문을 쇼더스에 넣어 만든 2단계 대본. 기준을 고치는 동안 판정기를 돌리지 않는다. 대본 글은 저장할 때 한 번 봤다
- 참조 판정자: 판정기 답을 보지 않은 서브에이전트 둘(참조A Opus 5.5, 참조B Sonnet 5.5). 기준표를 고치면 새 기준표로 다시 판정한다(`data/reference/<기준표 버전>/`)
- 판정 설정: 반복 중에는 Opus 5.5 · low · 표준 속도. 요금은 `runs/eval/ledger.jsonl`에 쌓는다
